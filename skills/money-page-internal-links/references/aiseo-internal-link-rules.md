# Internal link rules (money pages, top-down)

1. **Direction:** Product/service **money pages** link **out** to supporting blogs and related money pages. Do not plan blogs linking into money pages for this skill.
2. **Money set:** Page sitemap minus utilities (contact, privacy, blog hub, service-area hub, thank-you, etc.). Rank priority with GSC impressions/queries.
3. **Destinations:** Suggested `targetUrl` values are blog posts and/or other money pages that support the primary commercial page topic.
4. **Anchors:** `anchorText` is a **suggested** 2–6 word topic hint. Apply must pick a natural phrase **already on the page** (suggest, do not force). Never invent “Learn more about …” sentences.
5. **Weave:** Spread links across different Elementor text sections (one new link per section per run). Do not stack every outbound link in the hero intro.
6. **Uniqueness:** At most one link row per money URL + target URL pair. Prefer at most two outbound links per money page in the plan.
7. **Forbidden:** Never use service-area, location, or SAP URLs as destinations.
8. **Apply:** Hub Neo MCP edits the **money page** Elementor text-editors (or classic `post_content`) by wrapping an existing phrase only.
